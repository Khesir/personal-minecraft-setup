# 🎮 Minecraft Server Setup

Docker-based Minecraft server with Traefik reverse proxy and Crafty Controller web panel.

---

## 📋 Prerequisites

- A DigitalOcean droplet (Ubuntu 24.04)
- A domain name with DNS access
- SSH access to your droplet

---

## 🌐 Step 1 — Domain DNS Setup

Before anything else, point your domain to your droplet IP.

Go to your domain registrar (Namecheap, Cloudflare, etc.) and add these DNS records:

| Type | Name | Value | TTL |
|------|------|-------|-----|
| A | `@` | `your.droplet.ip` | Auto |
| A | `crafty` | `your.droplet.ip` | Auto |

> ⏳ DNS propagation takes 5–30 minutes. You can check with:
> ```bash
> nslookup crafty.yourdomain.com
> ```

---

## 🖥️ Step 2 — Droplet Initial Setup

SSH into your droplet:
```bash
ssh root@your.droplet.ip
```

Update the system:
```bash
apt update && apt upgrade -y
```

Install Docker:
```bash
curl -fsSL https://get.docker.com | sh
```

Install Docker Compose plugin:
```bash
apt install docker-compose-plugin -y
```

Verify both are installed:
```bash
docker --version
docker compose version
```

---

## 📁 Step 3 — Project Setup

Clone this repostory
```bash
git clone
```

Or create them directly on the droplet using `nano`:
```bash
nano docker-compose.yml
nano .env
```

---

## ⚙️ Step 4 — Configure .env

Edit your `.env` file and fill in your actual values:
```bash
nano .env
```

```env
DOMAIN=yourdomain.com
CRAFTY_SUBDOMAIN=crafty.yourdomain.com
ACME_EMAIL=your@email.com

MC_VERSION=LATEST
MC_TYPE=PAPER
MC_MEMORY=3G
MC_MAX_PLAYERS=10
MC_VIEW_DISTANCE=10
MC_DIFFICULTY=normal
MC_MOTD=My Minecraft Server
MC_OPS=yourMinecraftUsername
MC_LEVEL=world

TZ=Asia/Manila
```

> 🔑 `MC_OPS` is your Minecraft Java Edition username — this gives you operator (admin) access in-game.

---

## 🌍 Step 5 — Upload Existing World (Optional)

If you have an existing world you want to use:

**Find your world locally:**
- Windows: `%appdata%\.minecraft\saves\YourWorldName`
- Mac: `~/Library/Application Support/minecraft/saves/YourWorldName`
- Linux: `~/.minecraft/saves/YourWorldName`

**Upload to droplet:**
```bash
# From your LOCAL machine
scp -r /path/to/YourWorldName root@your.droplet.ip:~/minecraft/mc-data/world
```

> ⚠️ The folder must be named `world` (or match the `MC_LEVEL` value in your `.env`).

Alternatively, after setup you can upload it via the **Crafty Controller file manager** in the browser.

---

## 🚀 Step 6 — Start Everything

```bash
cd ~/minecraft
docker compose up -d
```

Check that all containers are running:
```bash
docker compose ps
```

You should see `traefik`, `crafty`, and `minecraft` all with status `Up`.

Watch Minecraft server logs (it takes 2–3 minutes on first boot):
```bash
docker logs -f minecraft
```

Wait until you see:
```
[Server thread/INFO]: Done! For help, type "help"
```

---

## 🎛️ Step 7 — Access Crafty Controller

Open your browser and go to:
```
https://crafty.yourdomain.com
```

Default credentials:
- **Username:** `admin`
- **Password:** `crafty`

> ⚠️ Change your password immediately after first login!

---

## 🎮 Step 8 — Connect to Minecraft

Give your friends your domain or IP:
```
yourdomain.com
```
or
```
your.droplet.ip
```

Port `25565` is the default — they don't need to type it.

## 🛠️ Useful Commands

```bash
# View all container status
docker compose ps

# Restart a specific container
docker compose restart minecraft

# Stop everything
docker compose down

# Start everything
docker compose up -d

# View Minecraft logs live
docker logs -f minecraft

# Run Minecraft server commands (op, whitelist, etc.)

# Pull latest image updates
docker compose pull && docker compose up -d
```

## 🔧 Common Issues

**SSL cert not generating**
- Make sure DNS is fully propagated before starting
- Check Traefik logs: `docker logs traefik`

**Minecraft not starting**
- Check memory — make sure `MC_MEMORY` isn't higher than your droplet's RAM
- Check logs: `docker logs -f minecraft`

**Can't connect to server**
- Make sure port `25565` is open in DigitalOcean firewall
- Go to DigitalOcean dashboard → your droplet → **Networking** → **Firewall**
- Add inbound rule: TCP port `25565`

**Crafty page not loading**
- Wait 2–3 minutes after `docker compose up` for everything to initialize
- Check: `docker logs crafty`

---

## 🔒 DigitalOcean Firewall

Make sure these ports are open in your droplet's firewall:

| Port | Protocol | Purpose |
|------|----------|---------|
| 22 | TCP | SSH |
| 80 | TCP | HTTP (redirects to HTTPS) |
| 443 | TCP | HTTPS (Crafty panel) |
| 25565 | TCP | Minecraft |

Go to: **DigitalOcean Dashboard → Networking → Firewalls**
